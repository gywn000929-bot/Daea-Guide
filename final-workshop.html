구매·물류 AI 실무 워크숍

메일 작성부터 수량 검토까지, 업무 사례로 AI 활용을 연습합니다. 필요에 따라 반복 요청 기준과 Excel 자동화를 살펴보고, 검토한 결과와 요청문을 저장합니다.

준비 5 → 메일 12 → 수정 8 → 대조 12 → 저장 8분

과정 구성

기본 과정: 준비 → 메일 작성 → 표현 수정 → 수량 대조 → 결과 저장

통합 과정: 기본 실습 후 반복 요청 기준과 Excel 자동화를 추가로 살펴봅니다. 시간과 사용 환경에 따라 선택하실 수 있습니다.

Gemini 답변은 별도 Gemini 탭에서 받습니다. 이 페이지의 예시와 확인 기준을 나란히 보며 검토하시면 됩니다. 기존 자료는 ‘전체 참고 자료’에 모았습니다.

화면 준비

실습 화면 준비

  1. 이 실습 탭: 설명 읽기, 요청문 복사, 결과 확인
  2. Gemini 탭: 요청문 붙여넣기, 답변 받기

상단의 Gemini 열기를 선택하신 후 로그인 상태와 입력창을 확인해 주시기 바랍니다. 준비가 되시면 이 실습 탭으로 돌아와 주십시오.

실습 전 확인 사항

연습 중 메일을 실제로 발송하지 않습니다. 회사 자료를 사용하게 되면 회사의 AI 사용 기준부터 확인합니다.

진행 참고 · 실습 취지 안내

“계장님, 오늘은 메일 작성과 수량 검토 사례를 중심으로 Gemini의 업무 활용 방법을 함께 살펴보겠습니다. 필요한 조작은 옆에서 안내드리겠습니다.”

진행 방식: 각 단계의 목적을 간단히 안내드린 후, 직접 조작하실 시간을 충분히 확보합니다. 다음 단계로 이동하기 전에 추가 설명이 필요하신 부분이 있는지 여쭙고 진행합니다.

접속이 지연되는 경우: 로그인이나 접속에 3분 이상 걸리면 각 단계의 ‘확인용 예시’를 펴고 요청과 검토 흐름을 먼저 설명합니다. 이 경우 Gemini 실행까지 완료한 것으로 체크하지 않습니다.

02 · 첫 메일 만들기 · 약 12분

업무 조건에 맞는 메일 작성

주요 확인 사항: ‘추가로 필요한 수량’과 ‘추가 후 총수량’을 구분합니다.

실습 사례

F2 공장의 DEMO-001 품목을 18,000개 더 받아야 합니다. 한 박스에는 4,000개가 들어가고, 부분 박스는 허용하지 않습니다. 꽉 찬 박스로 맞추기 위해 추가 발주가 필요한지 확인하고 영문 메일 초안을 만듭니다.

공장 / 품목현재 잔량한 박스조건
F2 / DEMO-00118,000 EA4,000 EA부분 박스 불가

EA = 낱개 수 · 잔량 = 아직 받지 못한 수량 · P/O = 발주서 또는 발주 건

실습 진행 순서

  1. 이 탭에서 아래 요청문을 읽고 요청문 복사를 누릅니다.
  2. Gemini 탭의 새 대화 입력창에 Ctrl + V로 붙여넣고 전송합니다.
  3. 답변이 나오면 이 탭으로 돌아와 아래 ‘숫자 확인’을 펼칩니다.
구매·물류 업무 담당자의 관점에서 검토해 주세요. 아래 연습 조건에 따라 추가 발주 수량을 계산하고 영문 메일 초안을 작성해 주세요.

공장: F2
품목: DEMO-001
현재 잔량: 18,000 EA
한 박스 수량: 4,000 EA
포장 조건: 부분 박스 불가. 모든 수량을 완전한 박스로 맞춤.
수신자: Ms. Ying

다음 순서로 답변해 주세요.
1. 박스 수, 추가로 필요한 수량, 추가 후 총수량을 계산식과 함께 한국어로 설명
2. 영문 메일 제목
3. 추가 수량과 총수량을 구분한 정중한 영문 본문 3문장 이내

제공되지 않은 납기나 출하 일정은 추가하지 말아 주세요. 서명은 [Name]으로 표기해 주세요.
복사 버튼이 안 되면 요청문을 드래그해 Ctrl+C로 복사해 주십시오.
계산 근거 및 메일 예시 · 답변 확인 후 참고
추가 2,000 EA · 총 20,000 EA · 5박스
18,000 ÷ 4,000 = 4.5박스 → 완전한 5박스
5 × 4,000 = 20,000개 → 20,000 − 18,000 = 2,000개 추가

메일의 표현은 예시와 다를 수 있습니다. 다만 추가 수량은 2,000개이며, 20,000개는 추가 후 총수량입니다. 납기와 출하일은 제공된 정보에 없으므로 포함하지 않습니다.

아래는 설명용 예시이며 실제 Gemini가 반환한 답변이 아닙니다.

Subject: Additional P/O Request – F2 / DEMO-001 Dear Ms. Ying, Please arrange an additional P/O for 2,000 EA of DEMO-001 for F2 to meet the full-box requirement of 4,000 EA per box. This will bring the total quantity from 18,000 EA to 20,000 EA (5 full boxes). Best regards, [Name]

메일 검토 체크리스트

체크는 직접 확인한 기록입니다. 이 페이지가 AI 답변을 자동 판정하지는 않습니다.

진행 참고 · 계산 근거와 메일 내용 검토

“계장님, 이번 사례는 4,000개 단위로 포장해야 하므로 총 5박스가 필요합니다. 추가 2,000개와 총 20,000개가 메일에 구분되어 있는지 함께 확인하겠습니다.”라고 안내드립니다. 자연스러운 문장뿐 아니라 업무 조건의 정확성을 확인하는 취지를 설명드립니다.

답변에 오류가 있는 경우: 같은 대화에서 “현재 잔량은 18,000개입니다. 5박스로 맞출 때의 추가 수량과 총수량을 구분하여 다시 계산해 주세요.”라고 수정 요청하실 수 있도록 안내드립니다.

기존 메일의 표현 수정

수정하실 내용과 유지할 조건을 구분하여 요청합니다.

기존 Gemini 대화에서 수정 요청

앞서 작성한 영문 메일을 더 간결하게 수정해 주세요.
인사와 서명을 제외한 본문을 2문장 이내로 작성해 주세요.
공장 F2, 품목 DEMO-001, 추가 2,000 EA, 총 20,000 EA는 그대로 유지해 주세요.
제공되지 않은 납기나 출하 일정은 추가하지 말아 주세요. 제목도 함께 제시해 주세요.

Gemini 탭에서 첫 메일을 만든 대화의 입력창에 붙여넣습니다. 답변이 나오면 이전 답변과 비교해 주시기 바랍니다.

수정 요청 시 참고하실 기준

답변을 수정하실 때는 변경할 내용과 유지할 조건을 함께 명시하시면 됩니다.

진행 참고 · 업무에 맞는 표현 조정

“계장님께서 평소 사용하시는 메일 형식에 맞춰 표현을 조정해 보겠습니다. 더 간결하거나 정중하게 바꾸고 싶으신 부분이 있으실까요?”라고 여쭙습니다. 말씀해 주신 내용을 요청문에 반영하고, 수량을 유지하는 조건도 함께 안내드립니다.

이미 첫 답변이 2문장이라면 ‘더 간결한 표현으로’라고 요청해도 됩니다. 문장 수를 줄이는 것보다 수정 후에도 업무 조건이 유지되는지 확인하는 것이 핵심입니다.

품목별 수량 차이 검토

메일에서 배운 ‘숫자 확인’을 표에도 적용해봅니다.

거래명세서와 실물 수량

수량 대조는 새 Gemini 대화에서 진행합니다

메일 작업과 다른 업무이므로 새 대화를 엽니다. 새 대화 버튼을 찾기 어렵다면 진행자와 함께 화면을 확인합니다.

아래는 연습용 거래명세서와 실물 수량입니다. 단위는 모두 EA입니다.
공장 | 품목 | 명세서 수량 | 실물 수량
F1 | DEMO-A | 3200 | 4000
F2 | DEMO-B | 2000 | 1000
F5 | DEMO-C | 5000 | 5000

차이 = 실물 수량 - 명세서 수량으로 계산해 주세요.
공장, 품목, 명세서, 실물, 차이, 판단(과입/부족/일치), 확인할 일을 표로 정리해 주세요.
서로 다른 품목의 과입과 부족을 상쇄하지 말아 주세요.
차이의 원인, 반품 여부, 재출하 일정은 자료만으로 확정하지 말아 주세요.
마지막에 담당자에게 확인할 질문을 2개 작성해 주세요.
수량 대조 결과 및 검토 기준
품목계산판단
DEMO-A4,000 − 3,200 = +800800 EA 과입

합계 차이는 −200개지만, “200개만 추가 공급”으로 처리할 경우 품목별 차이가 해결되지 않습니다. DEMO-A 과입 800개와 DEMO-B 부족 1,000개는 각각 확인해야 합니다.

확인 질문 예: 품목별 실물 재계수 결과가 맞나요? 명세서 정정과 추가 공급 여부를 각각 어떻게 처리할지 확인해 주실 수 있나요?

원본과 답변의 대조 항목

진행 참고 · 품목별 검토가 필요한 이유

“합계 차이는 200개 부족으로 보이지만, 품목별로는 과입 800개와 부족 1,000개가 각각 발생했습니다. 따라서 두 품목의 처리 방향을 따로 확인하겠습니다.”라고 안내드립니다. 수량 계산 결과와 차이의 원인·처리 방안은 구분하여 검토한다는 점을 설명드립니다.

05 · 반복 요청 기준 · 선택 10분

반복 업무의 요청 기준

Gem은 반복적으로 사용할 역할과 답변 기준을 설정하는 기능입니다. 먼저 아래 지침을 일반 대화에서 검토하신 후 활용하실 수 있습니다.

반복해서 유지할 기준

  • 구매·물류 업무 담당자의 관점
  • 간결하고 정중한 메일 표현
  • 수량 계산 근거와 확인 사항 구분
  • 정보가 부족한 경우 먼저 질문

업무마다 새로 제공할 자료

  • 이번 공장과 품목, 실제 수량
  • 최신 재고와 자료의 기준일
  • 이번 수신자와 요청 목적
  • 확인된 일정과 변경 사항

반복 요청 지침 예시

아래 지침을 복사하여 새 Gemini 대화에 입력하신 뒤, 이어서 이번 업무의 자료를 제공하시면 됩니다. 일반 대화에서의 검토만으로 Gem이 생성되지는 않습니다.

구매·물류 업무를 지원하는 관점에서 답변해 주세요.
1. 이번 대화에서 제공한 자료를 기준으로 검토해 주세요. 이전 예시의 숫자를 새 업무에 재사용하지 말아 주세요.
2. 수량을 계산할 때 공장, 품목, 단위와 기준일을 확인하고 계산 근거를 제시해 주세요.
3. 메일은 정중하고 간결하게 작성하고, 추가 수량과 총수량을 구분해 주세요.
4. 제공되지 않은 납기, 출하 약속, 원인은 추가하지 말아 주세요.
5. 자료가 부족하면 임의로 채우지 말고 필요한 사항을 질문해 주세요.
6. 답변 마지막에 담당자가 확인할 사항을 별도로 정리해 주세요.

누락된 조건이 있을 때도 확인해 보겠습니다

F2의 DEMO-002 품목 잔량은 9,000 EA입니다. 부분 박스는 허용하지 않습니다.
추가 발주 수량을 확인하고 싶습니다. 현재 한 박스 수량은 확인되지 않았습니다.
지금 계산할 수 있는지 검토하고, 먼저 확인할 정보를 알려 주세요.
확인 기준

한 박스 수량을 질문해야 합니다. 기존 실습의 4,000개를 가져와 추가 3,000개라고 단정하면 적절하지 않습니다. 이번 업무의 조건을 다시 확인해야 합니다.

선택 · 검토한 지침을 Gem으로 저장하실 경우
  1. Gemini에서 ‘Gems 탐색하기’ 또는 Gem 메뉴를 열고 ‘새 Gem’을 선택합니다.
  2. 이름을 정하고 검토한 반복 요청 지침을 입력합니다.
  3. 미리보기에서 누락 조건 예시로 답변을 확인한 후 저장합니다. 미리보기만으로 자동 저장되지는 않습니다.

06 · Excel 자동화 · 선택 20분

Excel 자동화 기준과 실행 확인

Windows 데스크톱 Excel이 준비된 경우에 진행하시면 됩니다. 웹용 Excel에서는 VBA를 실행할 수 없습니다.

자동화 작업 기준 정리

반복하는 Excel 작업의 자동화 기준을 정리하고자 합니다.
연습 상황: 제목은 1행이며 FAC / Item CD / Q'ty 열이 있습니다.
요청 작업: F2 행은 연노랑, F5 행은 연파랑으로 구분하고 표에 테두리를 적용합니다.
보존 조건: 원본 시트는 그대로 두고 복사 시트에서 작업합니다. 값과 수식을 변경하거나 행을 정렬·삭제하지 않습니다.
코드는 아직 작성하지 말아 주세요. 먼저 확인할 질문 3개와 결과 검토 체크리스트를 작성해 주세요.

현재 단계에서는 원본 보존, 대상 범위, 작업 내용, 결과 확인 기준을 정리합니다.

실행 체험 · Excel이 준비된 경우

연습 파일에서 첫 실행

아래 코드는 안내창만 표시합니다. 셀의 값이나 서식을 변경하지 않습니다. 파일 경로나 외부 연결도 사용하지 않습니다.

  1. Excel에서 새 빈 통합문서를 열어 주십시오. 업무 파일과 구분하여 진행합니다.
  2. Alt + F11로 VBA 편집기를 엽니다.
  3. 왼쪽에서 새 통합문서를 선택한 후 삽입 → 모듈을 선택합니다.
  4. 아래 코드를 복사하여 새 모듈의 빈 화면에 붙여넣습니다.
  5. Excel로 돌아와 Alt + F8을 누르고 DAEA_Practice_Hello를 선택하여 실행합니다.
  6. ‘첫 실행을 확인했습니다’라는 안내창이 표시되는지 함께 확인합니다.
Option Explicit

Sub DAEA_Practice_Hello()
    MsgBox "첫 실행을 확인했습니다. 셀 값은 변경하지 않았습니다.", vbInformation, "DAE-A 실습"
End Sub
회사 정책으로 매크로가 차단된 경우 보안 설정을 변경하지 않고 설명 단계까지만 진행합니다. 코드를 보관하시려면 ‘Excel 매크로 사용 통합문서(.xlsm)’로 저장하시면 됩니다.

Microsoft 공식 MsgBox 안내 · 이 단계는 실행 원리를 확인하는 체험입니다. 실제 수량 매칭이나 서식 자동화를 완료한 것은 아닙니다.

요청문을 작성하실 때는 업무, 자료, 원하는 결과, 확인 기준의 네 가지를 참고하시면 됩니다.

담당 업무에 맞춘 요청문 작성

마무리 확인 사항

TXT에는 요청문, 입력한 답변, 메모와 확인 기록이 담깁니다. 다른 PC에서 계속하려면 TXT를 보관해 주시기 바랍니다. PDF는 브라우저 인쇄창에서 ‘PDF로 저장’을 선택합니다.

추가 실습은 왼쪽의 반복 요청 기준과 Excel 자동화에서 진행하실 수 있습니다. 기본 과정만 진행하신 경우에는 이 화면에서 결과를 저장하시면 됩니다.
