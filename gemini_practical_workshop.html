Outlook + 메모장

한 업무의 메일만 모으세요

  1. 같은 품목이나 발주번호의 요청 메일과 최신 회신을 엽니다. 다른 업무의 메일은 빼세요.
  2. 메모장에 날짜, 제목, 보낸 사람, 본문을 순서대로 복사합니다. 중요한 표가 첨부에 있다면 그 파일도 준비합니다.
  3. 실제 메일이 아직 없다면 006강의 연습 예시부터 해도 됩니다.

여기까지 되면 다음으로: 무엇을 요청했고 마지막에 무엇이 바뀌었는지 원문에서 찾을 수 있습니다.

업무 상황

요청과 회신이 여러 메일에 흩어져 있고, 중간에 수량이 변경되었습니다.

핵심 원리

자료의 양보다 의사결정 흐름이 중요합니다. 요청·변경·확정 메일을 함께 제공해야 과거 요청을 현재 조건으로 적용하는 일을 줄일 수 있습니다.

지금 할 작업

  1. 다운로드한 메일에서 같은 P/O 또는 같은 품목에 관한 메일 3~5건을 고릅니다.
  2. 요청 메일 → 회신 → 최신 변경사항 순서로 정리합니다.
  3. 보낸 날짜·보낸 사람·제목·본문을 함께 남깁니다. 첨부 Excel이 판단 근거라면 별도로 준비합니다.
  4. 회사에서 사용이 허용된 계정과 자료 범위인지 확인합니다. 실습에 불필요한 개인정보는 제외합니다.
.msg 또는 .pst 파일만 있는 경우

Gemini가 내용을 읽었다고 확인되기 전에는 분석을 맡기지 않습니다. Outlook에서 관련 메일을 열어 날짜·제목·본문을 텍스트 파일에 옮깁니다. 확장자만 .txt로 바꾸면 변환되지 않습니다.

아래 코드는 동일한 실습 조건을 위한 참고용입니다. 이 교재에서 Excel 실행 검증을 완료한 코드는 아니므로 같은 샘플 확인 절차를 적용합니다.

Option Explicit

Public Sub MakeAirPrint()
    Dim wb As Workbook, src As Worksheet, dst As Worksheet
    Dim lastCell As Range, area As Range
    Dim headers As Variant, i As Long, r As Long, lastRow As Long
    Dim baseName As String, newName As String, suffix As Long
    Dim oldScreen As Boolean
    oldScreen = Application.ScreenUpdating
    On Error GoTo Fail

    Set wb = ThisWorkbook
    Set src = wb.Worksheets("AIR_SAMPLE")
    headers = Array("FAC", "Item code", "Maker", "Part Name", "Q'ty", "Unit")
    For i = 0 To 5
        If CStr(src.Cells(1, i + 1).Value2) <> headers(i) Then
            Err.Raise vbObjectError + 101, , "Header mismatch at column " & (i + 1)
        End If
    Next i
    Set lastCell = src.Range("A:F").Find(What:="*", After:=src.Range("A1"), _
        LookIn:=xlFormulas, LookAt:=xlPart, SearchOrder:=xlByRows, _
        SearchDirection:=xlPrevious, MatchCase:=False, SearchFormat:=False)
    If lastCell Is Nothing Then Err.Raise vbObjectError + 102, , "No data"
    lastRow = lastCell.Row
    If lastRow < 2 Then Err.Raise vbObjectError + 103, , "No data rows"

    baseName = "AIR_PRINT_" & Format(Now, "yymmdd_hhnnss")
    newName = baseName
    Do While AirSheetExists(wb, newName)
        suffix = suffix + 1
        newName = baseName & "_" & CStr(suffix)
    Loop
    Application.ScreenUpdating = False
    src.Copy After:=wb.Sheets(wb.Sheets.Count)
    Set dst = wb.Sheets(wb.Sheets.Count)
    dst.Name = newName
    Set area = dst.Range("A1:F" & lastRow)
    With area
        .Font.Name = "Malgun Gothic"
        .Font.Size = 11
        .Font.Color = RGB(0, 0, 0)
        .VerticalAlignment = xlCenter
        .Borders.LineStyle = xlContinuous
        .Borders.Weight = xlThin
        .Borders.Color = RGB(0, 0, 0)
    End With
    With dst.Range("A1:F1")
        .Font.Bold = True
        .Interior.Color = RGB(223, 234, 228)
        .HorizontalAlignment = xlCenter
    End With
    dst.Columns("A").ColumnWidth = 8
    dst.Columns("B").ColumnWidth = 17
    dst.Columns("C").ColumnWidth = 14
    dst.Columns("D").ColumnWidth = 38
    dst.Columns("E").ColumnWidth = 14
    dst.Columns("F").ColumnWidth = 9
    dst.Range("D1:D" & lastRow).WrapText = True
    dst.Range("E2:E" & lastRow).NumberFormat = "#,##0.########"
    dst.Rows("1:" & lastRow).AutoFit
    For r = 3 To lastRow
        If CStr(dst.Cells(r, 3).Value2) <> CStr(dst.Cells(r - 1, 3).Value2) Then
            With dst.Range("A" & r & ":F" & r).Borders(xlEdgeTop)
                .LineStyle = xlContinuous
                .Weight = xlMedium
            End With
        End If
    Next r
    With dst.PageSetup
        .PrintArea = area.Address
        .Orientation = xlLandscape
        .PaperSize = xlPaperA4
        .Zoom = False
        .FitToPagesWide = 1
        .FitToPagesTall = False
        .PrintTitleRows = "$1:$1"
    End With
    Application.ScreenUpdating = oldScreen
    MsgBox "Created: " & newName & vbCrLf & "Data rows: " & (lastRow - 1), vbInformation
    Exit Sub
Fail:
    Application.ScreenUpdating = oldScreen
    MsgBox "Error " & Err.Number & ": " & Err.Description & vbCrLf & _
        "Source sheet was not edited. Check any copied result sheet.", vbExclamation
End Sub

Private Function AirSheetExists(ByVal wb As Workbook, ByVal sheetName As String) As Boolean
    Dim sh As Object
    For Each sh In wb.Sheets
        If StrComp(sh.Name, sheetName, vbTextCompare) = 0 Then
            AirSheetExists = True
            Exit Function
        End If
    Next sh
End Function

핵심 원리

역할은 범위를 정하고, 처리 순서와 결과 형식은 실제 행동을 정합니다. 모호한 가치 표현보다 구체적인 처리 조건을 씁니다.

지금 할 작업

  1. PC에서 Gemini 웹을 엽니다.
  2. 왼쪽 메뉴의 Gems 또는 Gem 탐색에서 새 Gem 만들기를 엽니다. 계정과 화면에 따라 명칭이 다를 수 있습니다.
  3. 이름을 ‘구매·물류 업무 도우미’로 입력합니다.
  4. 요청 사항 입력란에 아래 내용을 붙여넣고 실제 업무 기준에 맞게 수정합니다.
역할: 구매·물류 업무의 자료 정리, 계산 확인, 영문 메일 초안 작성을 돕는다.

처리 순서
1. 목적, 대상 공장·P/O·품목, 자료 기준일을 확인한다.
2. 제공 자료의 사실, 계산 결과, 확인이 필요한 사항을 분리한다.
3. 수량 계산은 단위와 포함·제외 범위를 확인하고 계산식을 제시한다.
4. 메일이나 표를 요청한 형식으로 작성한다.

업무 기준
- F2와 F5 등 공장을 섞지 않는다. 품목 코드의 앞자리 0과 하이픈을 유지한다.
- Box Q’ty와 부분 박스 허용 여부가 없으면 먼저 질문한다.
- 메일의 요청·예정·확정·완료를 구분한다.
- 제공하지 않은 납기, 재고, 승인 여부를 만들지 않는다.
- 자료가 충돌하면 출처와 날짜를 나란히 보여 주고 적용 기준을 확인한다.
- 지식 파일의 예시는 현재 업무의 실제 값으로 사용하지 않는다.

결과 형식
- 영문 메일은 기본 2~4문장으로 작성한다. 과도한 사과나 책임을 돌리는 표현은 피한다.
- 계산이 있는 경우 계산식과 메일 본문을 분리한다.
- Excel 작업은 실제 시트명·열 이름·기준일을 먼저 확인한다.
- VBA는 요청이 있을 때 작성하고, 원본 보존과 복사본 실행을 기본으로 한다.
- 근거가 부족하면 “확인 필요”라고 표시한다.

이 기준과 다른 요청이 오면 변경된 조건을 명시하고 반영한다.

공장별 처리와 누락 정보 확인 등 반복 규칙이 요청 사항에 들어 있습니다.
