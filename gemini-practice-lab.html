이 페이지와 Gemini, 두 탭을 사용합니다

  1. 이 페이지: 아래 버튼으로 메일 실습을 열고 예시값을 그대로 둡니다.
  2. Gemini: 복사한 요청문을 새 채팅에 붙여넣고 답변을 받습니다.
  3. 이 페이지: 돌아와 답변의 수량을 확인하고 작업함에 저장합니다.

이전에 입력한 내용이 보이면 “18,000 / 4,000” 예시 버튼을 눌러 수량을 맞춰주세요.

낯선 단어는 여기서 확인하세요
요청문 / 프롬프트
Gemini에게 보내는 부탁입니다. 예: “아래 수량을 계산하고 메일을 써 줘.”
P/O
발주서 또는 발주 건을 뜻합니다. 추가 P/O는 필요한 수량을 더 발주하는 일입니다.
EA / Box Q’ty
EA는 낱개 수, Box Q’ty는 한 박스에 담는 낱개 수입니다.
FAC / Maker
FAC는 공장 구분, Maker는 제조사입니다. F1·F2·F5는 이 교재의 공장 구분 예시입니다.
Gem
반복해서 부탁할 역할과 답변 기준을 저장한 Gemini 도우미입니다.
VBA / 매크로
Excel이 할 일을 적는 언어 / 실행할 작업 묶음입니다.
대조 / 검증
답변의 숫자나 내용을 원래 자료와 나란히 놓고 확인하는 일입니다.
