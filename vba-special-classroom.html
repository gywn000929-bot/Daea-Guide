WARM UP

VBA를 아주 쉽게 읽는 방법

VBA는 엑셀에게 “어디에서 무엇을 어떤 순서로 할지” 적어 주는 작업 지시입니다.

한 문장으로 이해하기

같이 볼 핵심사람이 하던 반복 순서를 엑셀이 다시 수행하도록 적어 둔 것이 매크로이고, 그 지시를 적는 언어가 VBA입니다.
Sub Practice()
    Range("A1").Value = "확인 완료"
End Sub
코드뜻
Sub Practice()Practice라는 작업 시작
Range("A1")A1 셀을 선택
.Value =셀에 값을 입력
End Sub작업 종료

실행 흐름

Alt + F11 편집기 열기 → 삽입 · 모듈 → 코드 넣기 → Alt + F8 → 매크로 선택 → 실행

설명 메모 보기

“코드를 외우는 시간이 아니라, 우리가 정한 업무 기준이 코드 어디에 들어가는지 찾아보는 시간입니다.”라고 시작하면 부담이 적습니다.

실수하기 쉬운 부분

모듈은 코드를 보관하는 새 종이와 같습니다. 기존 코드 중간에 붙이면 중복 선언이나 End Sub 오류가 날 수 있습니다.

.xlsx는 매크로를 저장하지 못합니다. 코드까지 저장할 파일은 .xlsm으로 저장합니다.

컴파일은 실행 전에 문법상 잘못된 부분이 있는지 확인하는 과정입니다.

PRACTICE A

ITEM AUTO FILL V6

FAC + ITEM CD를 하나의 조회 키로 사용해 Balance·Stock·입고수량을 채웁니다.

한 폴더에 실습 파일 준비

직접 하기실습 키트를 내려받아 압축을 풉니다. 실습대상과 Balance 파일은 열고, stock.xlsx와 입고.xlsx는 같은 폴더에 둡니다.
파일상태역할
ITEM_AUTO_FILL_실습대상.xlsx열기결과가 채워질 파일
F1_F2_F5_Balance_실습.xlsx열기미납수량 원본
stock.xlsx같은 폴더출고수량 원본
입고.xlsx같은 폴더입고수량 원본
설명 메모 보기

같은 ITEM CD라도 F1과 F2는 수량이 다릅니다. 그래서 품목만 찾지 않고 FAC까지 함께 봅니다.

V6 모듈 설치

  1. Alt + F11
  2. 왼쪽에서 설치할 VBAProject 선택
  3. 파일 → 파일 가져오기
  4. ITEM_AUTO_FILL_V6.bas 선택
  5. 디버그 → VBAProject 컴파일
  6. Ctrl + S
설명 메모 보기
가져오기는 긴 코드를 드래그해 복사하는 과정에서 줄이 빠지는 일을 줄여 줍니다. 기존 V5가 있다면 먼저 제거합니다.

        
첫 실행
직접 하기실습대상 시트를 선택합니다. Alt + F8에서 CF6_Fill_Active_Sheet를 실행합니다.
코드는 현재 시트에서 FAC, Item cd, Bal, Sto, In 열을 찾고, 원본의 같은 키를 합산해 결과를 씁니다.
잠깐 예측하기F1 PRACTICE-1001의 Balance 원본은 1,000과 800 두 행입니다. 실행 결과는 얼마여야 할까요?

        
예상 결과와 대조
아래 버튼은 VBA를 실행하지 않습니다. 예제 원본의 합산 결과를 보여 주므로, 실제 Excel 결과와 한 칸씩 비교하세요.
버튼을 누르면 예상값이 표시됩니다.
설명 메모 보기
0과 #N/A는 의미가 다릅니다. Stock·입고의 0은 일치 수량 없음, Balance의 #N/A는 원본에서 키를 찾지 못했다는 뜻입니다.

        
한 번 클릭 버튼 만들기
직접 하기실습대상 시트를 선택하고 Alt + F8에서 CF6_Install_One_Click_Button을 실행합니다.
시트에 생긴 ITEM AUTO FILL 버튼은 다음 주차에도 같은 매크로를 빠르게 실행하기 위한 바로가기입니다.

        
오류가 나면 먼저 볼 곳
증상을 선택하면 점검 순서가 나옵니다.

PRACTICE B
AIR CONFIRM 자동화 V10
담당별 Confirm을 AIR·REMAIN 목록에 연결하고, 확인용과 전달용 결과를 동시에 만듭니다.

      

      

        
연습 파일을 .xlsm으로 저장
직접 하기AIR 실습 키트를 내려받습니다. Excel 파일을 열고 다른 이름으로 저장 → Excel 매크로 사용 통합 문서 (*.xlsm)로 저장합니다.

        
입력과 출력 구분
구분시트역할
입력효주·경진·민지담당별 Confirm
입력화요일_AIRPurchase request 기준
입력수요일_REMAINRemain 기준
출력TUE_CONFIRM / THU_CONFIRM상태 확인
출력THAI_F1F2 / THAI_F5Outlook 전달용
검토CHECK중복 항목 확인
매칭 기준FAC + Item cd가 기본입니다. 결과는 FAC → Maker → Part Name 순으로 정렬됩니다.

        
V10 코드 설치
  1. Alt + F11
  2. 삽입 → 모듈
  3. AIR_CONFIRM_V10.bas 가져오기 또는 전체 코드 붙여넣기
  4. 디버그 → VBAProject 컴파일
  5. Ctrl + S

        
화요일 AIR 결과 만들기
직접 하기Alt + F8 → BuildTuesdayConfirm → 실행
예제에는 정상 Confirm, 빈 Confirm, 문자형 Confirm, 같은 FAC + Item cd 중복을 각각 넣어 두었습니다.
버튼을 누르면 예상 상태가 표시됩니다.
설명 메모 보기
STOCK이 요청수량보다 부족해도 Confirm에 날짜나 설명이 있으면 OK입니다. 부족하고 Confirm도 비어 있을 때 CHECKING입니다.

        
목요일 REMAIN 결과 만들기
직접 하기Alt + F8 → BuildThursdayConfirm → 실행
화요일은 Purchase request, 목요일은 Remain을 기준 수량으로 사용합니다. 나머지 매칭과 검증 흐름은 같습니다.

        
결과를 업무 기준으로 검증
상황을 선택하면 점검 순서가 나옵니다.
설명 메모 보기
매크로 완료 메시지는 실행이 끝났다는 뜻입니다. 업무 결과가 맞다는 보증은 아니므로 STATUS, CHECK, 분리된 태국 전달용 시트를 마지막에 확인합니다.
